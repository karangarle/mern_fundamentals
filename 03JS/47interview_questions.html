JavaScript Interview Questions

In questions ko sirf ratna nahi hai. Har answer ko teacher style me bolo: simple definition, small example, output, aur interview point.

1. Define One-line meaning bolo.
2. Example Small code ya real-life example do.
3. Output Result explain karo.
4. Caution Common mistake ya interview point bolo.

1. var, let, const me difference kya hai?

var function scoped hota hai, let aur const block scoped hote hain. const variable ko reassign nahi kar sakte.

Teach: Box example do: var old box, let changeable block box, const fixed label box.

2. Primitive aur reference data types me difference kya hai?

Primitive values direct value store karti hain. Reference types memory address store karte hain. Object aur array reference type hain.

Teach: Primitive photocopy jaisa, reference original file location jaisa.

3. == aur === me kya difference hai?

== value compare karta hai type conversion ke baad. === value aur type dono compare karta hai.

Teach: Interview me bolo: mostly === use karna safer hai.

4. Hoisting kya hoti hai?

JavaScript execution se pehle declarations ko memory me register kar leti hai. Function declaration pehle call ho sakti hai, var undefined deta hai, let/const TDZ me error dete hain.

Teach: Code run hone se pehle JS attendance register banata hai.

5. Closure kya hota hai?

Closure tab banta hai jab inner function outer function ke variable ko remember karta hai, even outer function execute ho chuka ho.

Teach: Counter example do: count private rehta hai but inner function usko update karta hai.

6. Callback function kya hota hai?

Callback ek function hota hai jo dusre function me argument ke form me pass hota hai aur baad me execute hota hai.

Teach: Pizza order example do: order do, ready hone par callback call hota hai.

7. Promise states kaun-kaun si hoti hain?

Promise ki 3 states hoti hain: pending, fulfilled, rejected. then success handle karta hai, catch error.

Teach: Online delivery example: pending, delivered, failed.

8. async/await promise se kaise different hai?

async/await promise ko readable style me likhne ka syntax hai. Internally promise hi use hota hai.

Teach: then/catch chain ko clean sentence jaisa banana async/await ka kaam hai.

9. Event loop kya karta hai?

Event loop call stack empty hone ke baad microtask queue aur callback queue se tasks execute karwata hai.

Teach: Synchronous code first, promise microtask second, setTimeout later.

10. for in aur for of me difference kya hai?

for in keys/index deta hai. for of iterable values deta hai.

Teach: Object keys ke liye for-in, array values ke liye for-of.

11. map, filter, reduce me difference kya hai?

map new transformed array banata hai, filter condition pass values rakhta hai, reduce array ko single result me convert karta hai.

Teach: map changes each item, filter selects items, reduce makes final total.

12. this keyword ka value kaise decide hota hai?

this ka value function kaise call hua us par depend karta hai. Object method me this object ko point karta hai.

Teach: this ko caller ke naam se explain karo: jisne function call kiya, this aksar wahi hota hai.

13. Prototype kya hota hai?

Prototype shared methods aur inheritance ka mechanism hai. Object method nahi milta to prototype chain me search hota hai.

Teach: Shared toolbox example do: har object apna copy nahi rakhta.

14. localStorage aur sessionStorage me difference kya hai?

localStorage data browser me tab close ke baad bhi rakhta hai. sessionStorage data tab/session close hone par remove hota hai.

Teach: localStorage permanent notebook, sessionStorage temporary rough page.

15. Spread aur rest operator me difference kya hai?

Spread values ko expand karta hai. Rest multiple values ko collect karke array banata hai. Dono syntax ... use karte hain.

Teach: Spread unpacking hai, rest packing hai.
