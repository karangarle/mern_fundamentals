Dark Mode Study Dashboard

JavaScript Learning + Interview Roadmap

Is page ko teacher mode me use karo: pehle concept samjho, phir code run karo, phir kisi beginner ko 2 minute me explain karne ki practice karo.

1. Read Topic ka simple meaning samjho.
2. Run Linked file open karke output dekho.
3. Change Example me values change karke test karo.
4. Teach Same topic kisi ko apni language me samjhao.

1. Basics

01. Variables

Data ko store karna sikho using let, const, variable name aur value.

Teach: Variable ko ek labelled box ki tarah explain karo.

Interview: let, const, var difference and naming rules.

02. Data Types

Primitive aur reference data samjho: number, string, boolean, null, undefined, bigint, object, array.

Teach: Har data type ka real-life example do.

Interview: typeof null, primitive vs reference, array typeof object.

03. Type Conversion

String, Number, Boolean conversion aur truthy/falsy values samjho.

Teach: User input string hota hai, calculation ke liye number banana padta hai.

Interview: "5" + 2 vs "5" - 2, Boolean("") and Boolean("0").

2. Operators + Conditions

04. Arithmetic Operators

Math calculation sikho: +, -, *, /, %, **.

Interview: modulus use case and exponent operator.

05. Assignment Operators

Variable ki value update karna sikho: +=, -=, *=, /=, %=.

Interview: x += 5 is same as x = x + 5.

06. Increment / Decrement

Value ko 1 se increase/decrease karna sikho using ++ and --.

Interview: pre-increment vs post-increment.

07. Comparison Operators

Do values compare karke true/false result lena sikho.

Interview: == vs === and != vs !==.

08. Logical Operators

Multiple conditions combine karna sikho using &&, ||, !.

Interview: short-circuit evaluation.

09. Ternary Operator

Simple if/else ko one-line expression me likhna sikho.

Interview: condition ? trueValue : falseValue.

10. Conditions

if, else if, else se decision making sikho.

Interview: condition order matters in else-if ladder.

11. Switch Statement

Ek value ko multiple cases se compare karna sikho.

Interview: break missing ho to fall-through hota hai.

3. Loops + Functions

12. Loops

Same code ko repeat karna sikho using loop concept.

Interview: loop condition, update, infinite loop.

13. While Loop

Jab condition true ho tab tak loop run karna sikho.

Interview: while loop condition pehle check karta hai.

14. Do While Loop

Code ko kam se kam ek baar run karna sikho, phir condition check hoti hai.

Interview: do while at least once execute hota hai.

15. For Loop

Fixed number of repetitions ke liye for loop use karna sikho.

Interview: initialization, condition, increment flow.

16. For In Loop

Object keys ya string indexes par loop chalana sikho.

Interview: for-in keys deta hai, values nahi.

17. For Of Loop

Array/string ke direct values par loop chalana sikho.

Interview: for-of iterable values deta hai.

18. Functions

Reusable code block banana sikho: normal function, arrow function, return value.

Interview: function declaration vs expression vs arrow function.

19. Scope

Variable kaha access ho sakta hai ye samjho: global, function, block scope.

Interview: var function scoped, let/const block scoped.

20. Callback Functions

Function ko dusre function me argument ki tarah pass karna sikho.

Interview: callbacks async programming ka base hain.

4. Error Handling + Data Structures

21. Try Catch Finally

Runtime errors ko handle karna sikho taki app crash na ho.

Interview: try, catch, finally execution flow.

22. Throw Error

Custom error create karna sikho using throw.

Interview: throw new Error() kab use karte hain.

23. Objects

Related data ko key-value pair me store karna sikho.

Interview: dot vs bracket access, method, this.

24. Arrays

Multiple values ko ordered list me store karna sikho.

Interview: index, length, sparse arrays.

25. Array Methods Part 1

Basic array methods sikho: push, pop, shift, unshift, splice, slice, map.

Interview: mutating vs non-mutating methods.

26. Array Methods Part 2

Advanced methods sikho: forEach, filter, find, reduce, some, every.

Interview: map vs forEach, filter vs find, reduce use case.

27. String Methods

Text modify/search karna sikho: trim, includes, slice, replace, split.

Interview: strings immutable hote hain.

28. Math Object

Common math utilities sikho: round, floor, ceil, random, min, max.

Interview: random number range formula.

29. Date Object

Date/time read karna sikho using Date object methods.

Interview: getMonth() zero-based hota hai.

5. DOM + ES6

30. DOM Manipulation

HTML elements ko JavaScript se select aur change karna sikho.

Interview: innerText vs innerHTML, style changes.

31. DOM Events

User actions handle karna sikho: click, keyup, input.

Interview: addEventListener vs inline onclick.

32. Template Literals

Backticks aur ${} se strings ko clean way me likhna sikho.

Interview: multiline strings and interpolation.

33. Destructuring

Object/array values ko direct variables me extract karna sikho.

Interview: object destructuring in function parameters.

34. Spread Operator

Array/object copy, merge aur expand karna sikho using ...

Interview: spread vs rest difference.

6. Interview Topics

35. Rest + Default Params

Default value aur unlimited arguments handle karna sikho.

Interview: rest collects values, spread expands values.

36. Hoisting

JavaScript execution se pehle declarations ko memory me kaise rakhta hai ye samjho.

Interview: var hoisting, function hoisting, temporal dead zone.

37. Closure

Inner function outer variable ko kaise remember karta hai ye samjho.

Interview: private variable, counter, lexical scope.

38. this Keyword

this kis object ko point karega ye function call style se samjho.

Interview: normal function this vs arrow function this.

39. Constructor + Class

Same structure ke multiple objects banana sikho.

Interview: class is syntactic sugar over prototype.

40. Prototype

JavaScript inheritance aur shared methods ka base samjho.

Interview: prototype chain and method lookup.

41. Map + Set

Map me key-value data aur Set me unique values store karna sikho.

Interview: object vs Map, array duplicate remove using Set.

42. JSON + localStorage

Object ko JSON string me convert karke browser storage me save karna sikho.

Interview: JSON.stringify, JSON.parse, localStorage stores strings.

43. Promise

Future async result handle karna sikho using then and catch.

Interview: pending, fulfilled, rejected states.

44. Async Await

Promise code ko readable synchronous style me likhna sikho.

Interview: await only inside async function.

45. Event Loop

Synchronous code, promise microtask, setTimeout callback order samjho.

Interview: call stack, microtask queue, callback queue.

46. Modules

Code ko multiple files me split karna sikho using import/export.

Interview: named export vs default export.

47. Interview Questions

Final revision ke liye common JavaScript interview questions practice karo.

Interview: har question ka answer example ke sath bolne ki practice karo.
